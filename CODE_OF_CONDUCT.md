# Code of conduct

We want this project to be a respectful place for everyone who uses or contributes to it.

- Be kind and assume good faith. Disagree with ideas, not with people.
- No harassment, discrimination, insults or personal attacks, in issues, pull requests or any other space linked to
  this project.
- Don't publish other people's private information, including API keys and credentials.

Maintainers may edit or remove comments, close issues and pull requests, and block accounts that break these rules.
To report a problem, write to contact@doconda.com.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
