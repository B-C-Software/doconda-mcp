# Security policy

## Supported versions

Only the latest published version of `@doconda/mcp` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's "Report a vulnerability" button on the
Security tab of this repository, or write to contact@doconda.com.

Include what you found, how to reproduce it and the version affected. We acknowledge reports within three working
days and tell you when a fix is released. Never include a working API key in a report.
